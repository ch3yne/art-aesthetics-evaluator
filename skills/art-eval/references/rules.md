# 视听语言美学评测规则

评测遵循以下维度。规则规定**关注方向**，具体判断结合素材实际表现。

> **素材依据底线**：prompt、文件名、页面标题、用户描述或“已知信息”不能替代视频画面/声音证据。若无法取得视频帧、音频依据或已有 `eval-work` 产物，应中断任务，等待用户安装好环境后重新发起。

> 维度分两类：**视觉维度**可由模型直接看画面判断；**听觉维度**（6）受模型模态限制，见下方"听觉评测的前提"。

## 评测维度

### 1. 运镜（Camera Movement）
- 镜头运动是否服务于叙事 / 情绪，而非炫技
- 运动是否流畅、稳定，有无生硬卡顿或失控漂移
- 推拉摇移跟的选择是否恰当
- I2V 场景：从静态首帧生发的运动是否自然合理

### 2. 构图（Composition）
- 画面布局、视觉重心、平衡感
- 主体是否突出，前后景关系是否清晰
- 是否符合或有意打破经典构图法则（三分、对称、引导线等）

### 3. 节奏（Rhythm / Pacing）
- 镜头时长、运动速度与内容情绪的匹配
- 视频内部节奏的连贯性
- 多镜头时的剪辑节奏感

### 4. 色彩（Color）
- 色调统一性与情绪表达
- 色彩搭配是否和谐 / 有意识的对比
- 是否存在 AI 生成常见的色彩漂移、闪烁

### 5. 光影（Light & Shadow）
- 光源逻辑是否一致、可信
- 明暗层次与立体感
- 光影对氛围的塑造

### 6. 听觉 / 声音（Audio & Sound）
- 配乐（BGM）/ 音效（SFX）/ 环境音是否贴合画面情绪与场景
- **音画同步**：声音与画面动作、节奏、剪辑点是否对位
- 声音的空间感、层次与响度动态是否自然
- 有无 AI 音频常见瑕疵：突兀切入 / 断裂、与画面不符、机械感、爆音
- **听觉评测的前提**：默认按当前模型无法直接"听"音频处理。必须基于以下可感知输入之一进行判断，并在报告中注明依据来源：
  1. 若所在平台明确支持直接输入音频，可直接使用音频文件作为依据
  2. 用 ffmpeg 导出的**声谱图（spectrogram）+ 波形图（waveform）** PNG，由模型读图分析（响度起伏、频段分布、断点、与画面剪辑点的时间对应）
  3. 用户提供的**文字描述 / 字幕 / 配乐说明**
  4. 若有外部 ASR / 转写文本，可纳入分析（本技能不内置 ASR）
  - 若以上输入都缺失，**如实声明"本 case 无可用音频依据，不做听觉判断"**，不得臆断。

### 7. 叙事服务性（Narrative Service）
- 上述视觉与听觉元素是否共同服务于一个清晰的表达意图
- **音画是否协同**：声音与画面是否指向同一情绪/叙事，而非各说各话
- 是否有"为美而美"但脱离内容的问题

## 非评分判断口径

报告与默认对话输出**不包含分数、权重、综合分或量化排名**。每个维度只给专业判断、证据与影响，避免把复杂的视听问题压缩成数字。

每个维度用以下非量化口径表达：

| 判断 | 含义 |
|------|------|
| 突出 | 元素协同、服务叙事，未见影响观看的明显问题 |
| 稳定 | 表现可靠，仅有轻微可优化点 |
| 基本成立 | 能达意，但存在可明确指出的短板 |
| 影响观看 | 问题已削弱观看体验或表达意图，需要优先修复 |
| 严重破坏 | 该维度出现明显崩坏，直接破坏可信度或可读性 |

多视频对比时，不做综合分排序。改为输出：
- **推荐结论**：更推荐哪个视频用于当前目标，或说明各自适用场景
- **关键胜出原因**：列出 2-4 个真正拉开差距的维度与证据
- **关键风险**：列出每个视频最影响可用性的短板
- **修复优先级**：按 P0 / P0i / P1 或“先修什么、再修什么”组织

> **证据优先原则**：任何判断都必须能在画面/声音依据里找到支撑。不要用空泛形容词替代具体帧、动作、构图、光影、节奏或音频依据。
