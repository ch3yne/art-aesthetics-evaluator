# 视听语言美学基础知识

> 本文件为按需加载的参考资料，供没有专业基础时查阅。Agent 在需要解释专业概念时引用本文件。

## 一、运镜术语

| 术语 | 含义 | 常见用途 |
|------|------|----------|
| 推（Push in） | 镜头向主体靠近 | 强调、聚焦情绪 |
| 拉（Pull out） | 镜头远离主体 | 交代环境、抽离 |
| 摇（Pan / Tilt） | 机位不动，镜头水平/垂直转动 | 展示空间、跟随视线 |
| 移（Tracking） | 机位平移 | 跟随运动、营造流动感 |
| 跟（Follow） | 镜头跟随主体移动 | 沉浸、代入 |
| 升降（Crane） | 垂直升降 | 宏大、揭示 |
| 手持（Handheld） | 模拟人眼晃动 | 真实、紧张、纪实感 |

**评判要点**：运镜的"好看"不在于复杂，而在于是否与情绪/叙事同频。

## 二、构图法则

- **三分法**：将画面横竖三等分，主体置于交叉点
- **对称构图**：庄重、稳定、仪式感
- **引导线**：用线条把视线引向主体
- **框架式构图**：用前景元素框住主体，增加层次
- **留白**：给画面呼吸空间，突出主体情绪
- **黄金分割 / 螺旋**：更自然的视觉重心分布

## 三、节奏与剪辑

- **镜头时长**：长镜头沉稳/沉浸，短切快剪营造紧张/兴奋
- **动作匹配剪辑（Match cut）**：通过动作或形状连接两个镜头
- **节奏曲线**：好的片段有起伏，而非匀速平铺
- AI 视频常见问题：节奏内部断裂、运动速度忽快忽慢

## 四、色彩

- **色温**：暖色（橙黄）亲近/温暖，冷色（蓝青）疏离/冷静
- **色彩和谐**：邻近色和谐，互补色对比强烈
- **饱和度**：高饱和鲜活，低饱和高级/克制
- AI 生成常见问题：帧间色彩漂移、局部闪烁、不自然的过曝

## 五、光影

- **三点布光**：主光、辅光、轮廓光，塑造立体感
- **硬光 vs 柔光**：硬光对比强烈/戏剧化，柔光柔和/唯美
- **光源逻辑一致性**：AI 视频要重点检查光源方向是否前后矛盾
- **明暗对比（Chiaroscuro）**：强对比营造戏剧张力

## 六、听觉 / 声音

> 模型无法直接听音频，本节概念用于解读 ffmpeg 导出的**声谱图/波形图**或用户的文字/字幕描述。

- **配乐（BGM）**：奠定情绪基调；主题动机（leitmotif）随叙事反复强化记忆
- **音效（SFX）**：动作、环境的真实感来源；需与画面事件对位
- **环境音 / 氛围声（Ambience）**：营造空间与临场感
- **音画同步（Sync）**：声音事件与画面动作/剪辑点在时间轴上对齐
- **声画对位（Counterpoint）**：声音有意与画面形成反差以制造张力，是技巧而非错误
- **响度动态 / 动态范围**：起伏自然 vs 全程一个音量（机械、廉价感）
- **如何看图判断**：
  - 波形图：振幅 = 响度；突变断崖 = 切入/断裂；长段平直 = 缺动态
  - 声谱图：纵轴频率、横轴时间、亮度=能量；可看低频(配乐铺底)/高频(音效/嘶声)分布与突兀断点
- AI 音频常见问题：音乐与画面情绪错位、音效缺失或滞后、循环痕迹明显、人声机械、片尾硬切

## 七、I2V 专项评估点

- **首帧还原度**：生成视频起始是否忠于参考图
- **延展合理性**：从静态图生发的运动/变化是否符合物理与逻辑
- **一致性**：主体形态、材质、光影在运动中是否保持稳定
- **常见崩坏**：肢体扭曲、物体融化、纹理抖动

## 八、AI 生成视频常见瑕疵清单（快速排查）

视觉：
- [ ] 主体形变 / 闪烁
- [ ] 光源方向前后矛盾
- [ ] 帧间色彩漂移
- [ ] 运动速度不自然（忽快忽慢）
- [ ] 背景细节崩坏 / 文字乱码
- [ ] 物理逻辑错误（穿模、融化、重力异常）

听觉（需有声谱图/波形/描述依据）：
- [ ] 配乐与画面情绪错位
- [ ] 音效缺失、滞后或与动作不对位
- [ ] 响度无动态（全程一个音量）或爆音
- [ ] 明显循环痕迹 / 片尾硬切断裂
