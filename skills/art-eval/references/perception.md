# 抽象感知 → 专业语言

把用户的主观感受映射到专业维度，并扩写为有依据的系统化表述。

用户评价是后续分析的**优先参考锚点**：先围绕用户评价定位维度、查找证据和组织结论，再补充其他重要问题。优先参考不等于无条件同意；如果素材证据只部分支持或不支持用户评价，需要明确说明差异。

## 工作方法

1. **提取评价**：保留用户评价原文，识别比较对象、偏好方向和关键词（如“第一个更好”“更流畅”“更有电影感”）
2. **定位维度**：判断用户的感受指向哪个/哪些专业维度
3. **优先找依据**：先从素材中寻找支持或修正该评价的具体画面/声音证据
4. **专业扩写**：用专业语言重述，但保留用户原意，不曲解
5. **证据校准**：结论分为“支持 / 部分支持 / 不支持或证据不足”，并说明原因

## 常见映射表

| 用户口语 | 可能指向的专业维度 | 专业扩写方向 |
|----------|-------------------|-------------|
| "运镜好看" | 运镜 + 节奏 | 镜头运动的流畅度、与情绪的匹配、稳定性 |
| "很流畅" | 节奏 + 运镜 | 运动连贯无卡顿、镜头衔接自然 |
| "画面高级" | 色彩 + 光影 + 构图 | 低饱和色调、光影层次、克制的构图 |
| "看着舒服" | 构图 + 色彩和谐 | 视觉重心稳定、色彩搭配协调 |
| "有电影感" | 光影 + 色彩 + 画幅 + 节奏 + 配乐 | 戏剧化布光、统一色调、沉稳节奏、配乐烘托 |
| "很假/出戏" | 光源逻辑 + 物理一致性 + 音画同步 | 光影矛盾、运动不自然、主体形变、声音与画面错位 |
| "节奏拖" | 节奏 | 镜头时长过长、缺乏起伏 |
| "配乐带感/燃" | 听觉 + 节奏 | 配乐情绪贴合、鼓点/重音与剪辑点对位、响度有起伏 |
| "音画不搭/声音出戏" | 音画同步 + 听觉 | 配乐情绪与画面错位、音效滞后或缺失 |
| "声音很空/单薄" | 听觉（空间感/层次） | 缺环境音与层次、动态范围窄 |

> 听觉类扩写必须基于声谱图/波形图或用户文字依据（见 `references/rules.md` 的「听觉评测的前提」）；无依据时如实说明，不臆断。

## 扩写示例

**用户输入**：视频1运镜比视频2好看

**专业扩写**：
> 视频1在运镜维度表现更优：其镜头运动（如缓推 / 横移）与画面情绪同频，
> 运动轨迹平滑稳定，无明显卡顿或失控漂移；镜头的起幅、运动、落幅有清晰节奏，
> 服务于对主体的强调。相较之下，视频2的运镜在 [具体画面] 处出现 [速度突变 / 抖动 / 与内容脱节] 的问题，
> 削弱了观看的沉浸感。

## 原则

- **不无中生有**：每个专业判断都要能在画面/声音里找到依据
- **优先参考用户判断**：扩写是"翻译+论证+校准"，先回应用户评价，再展开其他维度
- **保留但不盲从**：保留用户原意；若素材证据与评价不一致，说明不一致发生在哪些维度
- **避免堆术语**：术语服务于说清楚，不为显得专业而堆砌
