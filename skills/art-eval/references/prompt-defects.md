# 提示词契合度与缺陷优先级

本文件把用户提供的 prompt、人工总结、case 分析截图或问题分级，转化为可复用的评测上下文。
它不替代 `references/rules.md` 的七个视听维度，而是为“叙事服务性”“横向对比”“改进建议”提供更明确的目标与优先级。

## 适用输入

用户可能提供：
- 每个视频对应的一套 prompt
- 多个模型/版本的视频对比
- 已有人工总结、case 分析、问题截图
- 对某些问题的优先级标注，例如 P0 / P0i / P1

当视频与 prompt 成对出现时，必须先建立映射：

| 素材 | 对应 prompt | 补充上下文 |
|------|-------------|------------|
| 视频1 | ... | 用户观点 / 人工总结 / 问题帧 |
| 视频2 | ... | 用户观点 / 人工总结 / 问题帧 |

不要把不同视频的 prompt 混用；如果映射不清，先在回答中说明不确定点，再按可确认信息分析。

## 提示词契合度分析

对每个视频，从 prompt 中拆出以下目标：

1. **主体与关系**：谁与谁、主体身份是否清楚、对抗/协作/情绪关系是否成立
2. **动作与事件**：关键动作是否发生，动作强度是否符合 prompt
3. **场景与景别需求**：场景是否支持事件；景别是否能传达必要信息
4. **情绪与叙事张力**：画面是否传达 prompt 要求的情绪、冲突、节奏
5. **风格与质感**：色彩、光影、材质、氛围是否贴合 prompt

输出时给“提示词契合度”辅助判断：
- **高**：核心主体、动作、情绪与场景都服务于 prompt，且关键瞬间清晰可读
- **中**：大方向符合 prompt，但关键动作、景别、情绪或质感存在明显折损
- **低**：只保留了表层元素，核心事件/情绪/关系没有成立

默认不做量化。即使用户要求更细的比较，也优先用“高 / 中 / 低”和证据说明，不输出分数、权重或综合分。

## 缺陷优先级体系

按严重程度归纳问题，避免报告只罗列现象而没有处理优先级。

### P0：基础真实感与基础美感问题

这类问题会直接破坏观看可信度，优先指出。

- **运镜空间方位问题**：轴线或空间关系混乱，导致眩晕、方向错乱或对抗双方位置不可读
- **面部光影伪影**：面部横向光带、阴影遮挡、光照不符合光源逻辑
- **构图无端分屏 / 主次失衡**：单帧无动因地切成冗余两屏，破坏画面完整性
- **高速运动下肢体形变**：动作中身体、手脚、衣物或道具发生明显变形

### P0i：镜头叙事、光色一致性与质感真实度的系统性缺陷

这类问题不一定单帧崩坏，但会持续削弱叙事表达。

- **景别切换不服务叙事**：长期停留在中全景/全景，不推进近景、特写、正反打，导致张力被稀释
- **运镜替代了叙事设计**：环绕、远景、横移等运动本身没有问题，但没有服务人物情绪、视线关系或冲突升级
- **光源与主体割裂**：环境光、火光、魔法光等未映射到人物面部和身体，主体像被贴在背景上
- **色调脱离环境与风格**：人物、环境、特效的色彩不在同一风格系统里
- **皮肤/材质质感两极失控**：油腻蜡像感与过度磨皮之间摆动，缺少真实细节
- **运动真实度随时间衰减**：起初成立，后段动作、速度、物理关系逐渐失真

### P1：表现力与控制精度短板

这类问题影响表达质量和精细度，通常作为优化建议展开。

- **运镜速度失准**：该快不快、瞬时过快，或动作节奏与场面情绪不匹配
- **第一人称视点跑偏**：主观运镜中途退化为客观/侧向跟拍，削弱代入
- **蒙太奇 / 转场区分弱**：回忆与现实、段落切换或节奏变化不清晰
- **动态光影缺失**：光影没有随光源、动作或特效跳动
- **材质精细度落后**：面膜、面料、皮肤等细节廉价或不稳定
- **情感语言去人性化**：语速过快、缺少呼吸与共情，导致人物情绪不可信

## 对决场景校准样例

对于类似“创作一段哈利波特与伏地魔之间热血激烈的对战场面”的 prompt：

- 关键不是只出现两个人和魔法特效，而是要建立**对抗关系、情绪张力与关键动作可读性**
- 中全景/全景可以交代环境，但不能长期替代近景、特写、正反打
- 对决场景通常需要通过眼神、面部紧绷、施法反应、攻防节奏来支撑戏剧张力
- 环绕运镜本身不是问题；问题在于它是否服务于人物聚焦、冲突升级和空间关系
- 如果镜头始终停留在环境展示，观众会难以捕捉双方表情、情绪与对抗焦点

## 输出方式

在默认对话分析中，可加入：

1. **Prompt 对齐判断**：每个视频是否实现各自 prompt 的核心意图
2. **缺陷优先级**：按 P0 / P0i / P1 列出最关键问题
3. **与七个视听维度的关系**：说明这些问题分别影响运镜、构图、光影、节奏、叙事服务性等维度
4. **优化优先级**：先修 P0，再修 P0i，最后优化 P1

在正式报告中，如用户提供了 prompt 或人工总结，增加“提示词契合度与缺陷优先级”小节。
