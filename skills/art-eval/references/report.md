# 评测报告

把分析结果整理为结构化报告。本文件同时包含报告规则与完整模板，按模板结构输出，不要自行增删一级标题。

## 何时生成

报告是**可选**的：

- 用户只想看分析/对比结论 → 直接在对话里给，不必套模板。
- 用户明确要报告（“出一份报告”“整理成文档”“保存下来”“给出报告”）→ 按下面模板输出并落盘。
- 没有可用视频帧/音频依据，或 ffmpeg/ffprobe 跑不起来 → **不生成报告**，中断并提示用户修环境后重新发起。

## 落盘位置

| 场景 | 路径 |
|------|------|
| 批次目录模式 | `$BATCH_DIR/reports/评测报告-<批次目录名>.md` |
| 普通模式 | 当前目录 `评测报告-<标识>.md` |
| 当前目录本身是 `works/<批次号>` | 按批次模式处理，进该批次 `reports/` |
| 用户指定路径 | 用用户路径 |

用 Write 保存，保存后告知文件位置。

## 必须包含

1. **基本信息**：Case 类型（T2V / I2V）、素材数量、音频依据来源、prompt 是否成对提供
2. **核心结论**：一句话总结；有用户评价时先回应评价，再给推荐结论与关键差异
3. **维度判断总览**：各维度非量化判断 + 关键依据
4. **用户观点呼应**：仅在用户给了评价时写，说明支持 / 部分支持 / 证据不足
5. **提示词契合度与缺陷优先级**：有 prompt 或人工总结时写，按 P0/P0i/P1 归纳
6. **逐维度分析**：运镜、构图、节奏、色彩、光影、听觉、叙事服务性
7. **横向对比**（多视频）：表格呈现
8. **改进建议**：针对欠佳项给可操作方向

# 模板

## 基本信息

- **Case 类型**：T2V（文生视频） / I2V（图生视频）
- **素材数量**：N 个视频 + M 张参考图
- **Prompt 映射**：无 / 视频1→prompt1，视频2→prompt2 ...
- **评测维度**：运镜、构图、节奏、色彩、光影、听觉、叙事服务性
- **音频依据来源**：声谱图/波形图 / 用户描述 / 字幕转写 / 无（不做听觉判断）

> 一句话总结。多视频时给出推荐结论、各自适用场景与关键差异，不输出分数或量化排名。

> 仅当用户提供了观点时填写。
>
> **用户观点**：（原文）
>

## 四、提示词契合度与缺陷优先级（有 prompt / 人工总结时）

### Prompt 对齐判断
- 视频1：高 / 中 / 低；依据：主体关系、关键动作、场景景别、情绪张力、风格质感
- 视频2：高 / 中 / 低；依据同上

### 缺陷优先级
- **P0**：基础真实感与基础美感问题
- **P0i**：镜头叙事、光色一致性与质感真实度的系统性缺陷
- **P1**：表现力与控制精度短板

> 说明这些问题分别影响哪些视听维度，以及优先修复顺序。

## 输出原则

- 结论先行，依据在后
- 有用户评价时以它作为组织线索优先回应，但所有回应必须有素材证据
- 专业但可读，每个判断有画面/声音支撑
- 不输出分数、权重、综合分或量化排名
- 多视频时必须有明确对比、推荐结论和关键风险，不能各说各话
